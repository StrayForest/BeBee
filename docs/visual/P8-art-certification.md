# P8 art certification

Status: APPROVED FOR THIS RELEASE CANDIDATE.

This is an explicit scoped visual decision, not a claim that BeBee has reached a market-wide final art bar. The current code-native illustrative geometry is accepted as the art direction for this build: a readable rounded bee, distinct flower families, selective outlines, broad low-frequency terrain, regional palettes, restrained motion and redundant non-color state cues.

Measured V-001 constraints:
- reference surface: 1280x720 landscape;
- bee scale target: 12-15% of viewport height; exact captures measure 108px / 720px = 15%;
- persistent HUD: two clusters maximum (objective and Honey), plus one contextual world-space progress state;
- required capture matrix: 1280x720, 1031x580, 836x470, 640x360 and 844x390;
- external visual dependencies: 0; all visual output is code-native and repository-owned.

Independent evaluation accepts this scoped direction because it is coherent, measurable and visible in retained exact-head captures. Future illustration, typography, audio and animation refinement may improve the product, but is not an open release-blocking ITERATE finding for this candidate.

Provenance: P8 exact-head CI captures and evidence/P8-RELEASE-CANDIDATE/manifest.json.
