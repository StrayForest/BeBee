# Third-Party Software & Assets

This file is the license ledger for external code, extensions, fonts, art, audio and other assets used by BeBee.

## Rule

Nothing third-party is considered approved for production merely because it is public on GitHub or free to download.

Before adding a dependency/asset to the repository:

1. identify the exact source URL;
2. identify the exact version/commit/file set;
3. verify the license text and commercial-use terms;
4. record attribution requirements;
5. confirm redistribution/modification rules;
6. add the entry below;
7. keep required license/copyright notices with the distribution.

If license status is unclear, do not import it.
